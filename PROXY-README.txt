ПОСТЕРЫ И TMDB В РОССИИ

Сайт сам определяет, что картинки TMDB не грузятся (или грузятся дольше 3 секунд),
и переключается на публичный сервис wsrv.nl (он же сжимает картинки). Это работает без настройки.

Если этого мало — поднимите свой бесплатный прокси (5 минут):
1. dash.cloudflare.com -> Workers & Pages -> Create -> Hello World -> Deploy.
2. Edit code -> вставьте содержимое файла tmdb-proxy-worker.js -> Deploy.
3. Скопируйте адрес воркера (https://что-то.workers.dev).
4. В файле firebase-config.js впишите его: export const PROXY_URL = "https://что-то.workers.dev";
   После этого через прокси пойдут и картинки, и запросы к API TMDB (актёры, трейлеры, админка).

Важно: я не мог проверить, как адрес workers.dev и wsrv.nl открываются именно из РФ.
Если *.workers.dev у вас тоже тормозит, привяжите к воркеру свой домен (Workers -> Triggers -> Custom Domains).
